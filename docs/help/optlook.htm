Theme:

- Theme: The theme that defines the look of RT#. See Themes
- Mode: Whether the theme uses its light or dark colors. System follows the light or dark mode of the operating system

Data providers:

- Show speed chart: Display the speed chart of each data provider in the data providers pane

Torrent listing:

- Row height: Height of each line of the torrent listing, in pixels. A smaller height displays more torrents at the same time
- Show state icon next to torrent name: Display an icon for the state of each torrent (downloading, seeding, paused...) to the left of its name

Grids:

- Alternate row colors: Slightly shade every other row of all grids, including the torrent listing and the Files, Peers and Trackers tabs, to make long rows easier to follow. The shade is set by the theme as DataGridAlternatingRowBrush
