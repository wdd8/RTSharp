When a tracker changes its address, or when you get a new passkey, you would have to replace the tracker of each torrent one by one. The mass tracker rewrite plugin replaces a tracker address by another one across all your torrents, in one pass.

Select "Mass tracker rewrite" in the Tools menu. The plugin fetches the trackers of all the torrents and displays the list of tracker addresses with the number of torrents using each of them. Select the tracker that you want to replace, enter the new address in the "Replacement..." field and click on "Go".

rtorrent:

rtorrent does not support natively replacing trackers in place, so a workaround is applied that removes, modifies and adds again the torrent. This has some undesired side-effects like losing the historical download and upload data of the torrent, and it requires a full rehash of the torrent after. For this reason, we recommend you to take rtorrent offline, replace the references to the tracker address in the session folder of rtorrent yourself, and start it up again. The plugin displays a warning before using the workaround.
