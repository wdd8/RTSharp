There are two ways to run RTSharp.Daemon on your server:

- Systemd service: install the rtsharp-daemon package (.deb, .rpm or .pkg.tar.zst). The package installs the ASP.NET Core .NET 10 runtime as a dependency, and the configuration file is /etc/rtsharp-daemon/appsettings.json. The service is not started or enabled by the installation, so you have to complete these steps:
  1. Set the user and group the daemon runs as: systemctl edit rtsharp-daemon, then add User= and Group= under [Service]. The .deb installer asks for the user and fills it in for you, but check it.
  2. Enable and start the service: systemctl enable --now rtsharp-daemon.
- Docker container: see the docker-compose.yml file of the daemon for an example configuration. An example configuration will be created upon the first startup.

Since RTSharp.Daemon performs the file operations on the torrent data (move, duplicate, remove), we strongly recommend you to run it under the same user as your torrent daemons. The configuration of the daemon is explained in the "Daemon configuration" chapter.

The mediainfo feature requires mediainfo to be installed on the server.
