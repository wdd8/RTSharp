RTSharp.Daemon reads its configuration from the appsettings.json file located in /etc/rtsharp-daemon if this folder exists, otherwise from the application folder. An example configuration is provided, here is how to set it up:

1. Generate the server certificate:

Type the following command in /etc/rtsharp-daemon to generate a public and a private certificate:

openssl req -x509 -newkey rsa:4096 -nodes -keyout private.pem -out public.pem -days 36500

2. Note down the thumbprint of the certificate:

openssl x509 -in public.pem -noout -fingerprint -sha256 | sed s/://g | cut -d= -f2

This is the thumbprint that you will enter in the Servers window of RT#.

3. Modify the configuration:

Open appsettings.json, set the port in ListenAddress and add the thumbprint of your client certificate to AllowedClients (see the "Connecting to a server" chapter). Then restart the daemon.

Settings

ListenAddress: List of addresses and ports the daemon listens to, for example [ "0.0.0.0:1234" ]
Certificate: PublicPem and PrivatePem, the paths of the server certificate files
AllowedClients: List of the thumbprints of the clients that are allowed to connect, this includes other servers if you transfer data between servers
Prometheus: Enabled, Path (default /metrics) and PollInterval, see below
DLBandwidth / UPBandwidth: Optional download and upload capacity of the server line, in bytes per second. They enable some visualizations and statistics
ScriptStorePath: Folder where the installed scripts are stored. By default, a "scripts" folder in the state directory
DatabasePath: Absolute path of the database of the daemon. By default, rtsharp.db in the state directory
DataProviders: The torrent daemons served by this daemon, see the "Data provider configuration" chapter
Logging: The standard log levels of the daemon

The state directory is the folder given by systemd in STATE_DIRECTORY, or the application folder otherwise.

Prometheus metrics

Optionally, you can enable Prometheus in appsettings.json to expose the upload and download totals of each tracker at the configured Path (default /metrics). PollInterval controls how often the daemon refreshes these metrics. The following metrics are exposed:

- rtsharp_tracker_uploaded_bytes
- rtsharp_tracker_downloaded_bytes
- rtsharp_data_provider_torrent_fetch_duration_seconds
- rtsharp_tracker_metrics_last_refresh_timestamp_seconds

* Granting access to RTSharp.Daemon is equivalent to granting shell access. The daemon implements a runtime scripting interface that can be used to perform any action, so add clients to AllowedClients with caution.
