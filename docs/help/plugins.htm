This chapter covers all the plugins that are included with RT#. Basically these plugins allow you to add some features to RT# in 3 different ways:

- Data providers: Plugins that connect RT# to a torrent daemon (rtorrent, qBittorrent, Transmission)
- Tools: Plugins that add their own menu items and windows, such as the auto integrify
- Looks: Plugins that change the appearance of the listing, such as the colored ratio

A plugin can be loaded several times, each loaded plugin is called an instance and has its own configuration file. For example you will have one instance of the rtorrent data provider for each rtorrent daemon you want to control. The configuration of the instances is explained in the "Adding a data provider" chapter.

The Plugins window

Click on the "Plugins" menu to display all the loaded plugin instances. When you select one instance, RT# displays its information:

- Instance GUID: Unique identifier of this instance
- Display name: Name of the instance
- Description: Description of the plugin
- Author: Author of the plugin
- Version: Version of the plugin
- Guid: Unique identifier of the plugin itself, it is the same for all the instances of a plugin

Some plugins have their own settings, in this case the settings button is enabled and opens the settings window of the plugin. Click on "Manage..." to add, edit or remove plugin instances.

Plugin compatibility

Each plugin declares the major version of RT# it has been made for. If you load a plugin that has been made for a different major version, RT# tells you that the plugin is incompatible and asks you if you want to load it anyway. Answering "Yes" may work, but the plugin can also crash or behave in a strange way, so we recommend you to get an updated version of the plugin instead.

* Plugins run inside RT# with the same access as RT# itself, only install plugins from sources you trust.
