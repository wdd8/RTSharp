There are many ways to add torrents: you can select "Add torrent..." in the File menu, or you can drag and drop a .torrent file or a link on the main window. In both cases you will get the Add torrent window.

1. Select the source:

- From file: Click on "Browse..." and select one or several .torrent files on your computer
- From URI: Enter a magnet link or the http address of a .torrent file, RT# will download it for you
- From clipboard (URI's): Add all the links contained in the clipboard, one link per line. Click on "Preview" to check what will be added

When you drop a file on the main window, "From file" is automatically selected, and when you drop a link, "From URI" is automatically selected.

2. Select the data provider:

Select the data provider that will download the torrent. As soon as you select one, RT# fills in the remote directory with the default save path of this torrent daemon.

3. Select the remote directory:

This is the directory on the server where the data will be saved. You can type it or click on "Browse..." to open the directory selector, which displays the folders of the server with their permissions, size and last modification date. In this window you can also create a new directory, or remove an empty directory with a right click.

4. Start torrent:

Check this option if you want the torrent to start immediately.

5. Duplication:

This part is optional and allows you to add the same torrent to other data providers at the same time. Select a target data provider and a remote directory, then click on "Add target". Repeat this procedure for all the targets you want. Once the torrent has been added and downloaded, RT# will duplicate it with its data on each target, as explained in the "Duplicating torrents" chapter.

Finally, click on the "Add" button.
