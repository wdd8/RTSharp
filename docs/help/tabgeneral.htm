When you select one torrent from the listing, the General tab displays its name, a progress bar and two groups of information.

Transfer:

- Time elapsed: Time since the torrent has been added, or the time it took to finish the download once it is finished
- Remaining: Estimated time left
- Ratio: Share ratio
- Downloaded / Uploaded: Amount of data transferred
- DL Speed / UP Speed: Current speeds
- Wasted: Amount of data that has been downloaded but discarded (ie. bad pieces)
- Seeders / Peers: Connected seeders and peers

Torrent info:

- Remote path: Location of the data on the server
- Created on / Added on: Dates of the torrent
- Info hash: Info hash of the torrent, right click on it and select "Copy" to copy it to the clipboard
- Comment: Comment of the torrent, if any
- Status: Last message of the torrent daemon about this torrent, for example a tracker or a disk error

Several torrents

If you select several torrents, the General tab displays a summary of the selection instead: the number of torrents and their global progress, the total amount of data downloaded, uploaded, wasted and remaining, the total speeds, the global ratio and ETA. The Torrent info group then displays the states of the selected torrents, the wanted size, the date they have been added, and the number of connections, trackers and labels involved.
