The look of RT# (colors, fonts, sizes and control templates) is defined by a theme. The default theme is named "Standard". You select the theme in the Look options.

Theme folders:

Each theme is a folder containing a Theme.axaml file and any other files it uses, located in the "themes" folder of the configuration folder (see Software installation). RT# writes its built-in themes there when their folder does not exist, so deleting the "Standard" folder restores the original "Standard" theme.

Writing a theme:

To start a new theme, copy the "Standard" theme folder, rename the copy and edit its files. Themes are written in Avalonia XAML. The root element of Theme.axaml is Styles, and it can contain resources, styles and control themes. Theme.axaml can include the other files of the theme by a relative path, for example <StyleInclude Source="GroupBox.axaml" />, or by an absolute path starting with avares://RTSharp.Theme/. A theme can use the controls and types of RT# and of the libraries it ships with, but not those of plugins.

Icons:

The icons of RT# are files in the "Icons" folder of the theme, and a theme changes an icon by replacing its file with one of the same name. svg, ico and gif images are supported.

svg icons are drawn in the text color of the light or dark mode. An ico icon is drawn in its own colors, unless ".mask" is added before its extension, for example "start.mask.ico".
