Select one or several torrents in the listing and right click on them, you will get the torrent menu. The actions are applied to all the selected torrents, even if they belong to different data providers: RT# sends each action to the right server and displays its progress in the action queue. If one of the selected data providers does not support an action, the menu item is disabled.

- Start: Start the torrents
- Pause: Pause the torrents, they stay connected to the peers but stop transferring
- Stop: Stop the torrents completely
- Force recheck: Verify the data of the torrents on the disk. RT# asks you to confirm with the number of torrents and the amount of data to check
- Reannounce to all trackers: Ask the trackers for new peers immediately
- Set label...: Add or remove labels, see the "Labels" chapter
- Move download directory...: Move the data of the torrents to another directory of the server, see the "Moving the download directory" chapter
- Download sequentially: Download the pieces in order, this is useful if you want to preview a video while it is downloading. When all the selected torrents already download sequentially, this item becomes "Do not download sequentially"
- Remove torrent: Remove the torrents from the daemon, the data stays on the disk
- Remove torrent & data: Remove the torrents and delete their data
- Get .torrent: Save the .torrent files of the torrents into a folder of your computer, each file is named after the info hash of its torrent
- Duplicate torrent & data to...: Add the torrent and its data to another data provider, see the "Duplicating torrents" chapter

When a torrent finishes rechecking and is fully complete, RT# can start it automatically for you. You can activate this in the Behavior options.

The Start, Pause and Stop actions are also available in the tool bar. When only one torrent is selected, these buttons are only enabled when they make sense, for example you cannot start a torrent that is already downloading.

Removing the data:

Before removing the data, RT# always asks you to confirm with the number of torrents and the amount of data that will be deleted. Moreover, if the data of a torrent is also used by another torrent on the same server (for example after a duplication on the same server), RT# displays the list of these torrents and warns you that removing the data will cause data access errors for them.

Plugins can add their own items to this menu, for example the auto integrify plugin adds "Align file integrity & recheck" just after "Force recheck".
