Select "Statistics" in the View menu to open the statistics window. It is divided in two parts:

1. Listing:

The statistics of all the torrents currently in the listing:

- Torrents: Number of torrents
- Seeding size: Total size of the torrents that are seeding
- Uploaded / Downloaded: Total amount of data transferred by these torrents
- Share ratio: Global share ratio

2. Daemons:

The all-time statistics of each torrent daemon, which also include the torrents that have been removed:

- All-time upload / All-time download: Total amount of data transferred since the daemon has been installed
- All-time share ratio: Global share ratio of the daemon

rtorrent does not keep any all-time statistics, in this case RT# displays the message "One or more daemons do not support all-time statistics".

The statistics window is a tool window, it can be docked in the main window like any other pane.
