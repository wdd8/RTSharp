RT# keeps some information in local caches so it doesn't have to ask the servers or the internet again and again. The caches are saved in the configuration folder.

Files cache:

- Enable files caching: Keep the list of files of each torrent in the cache
- Concurrent peer caching requests: Maximum number of peer origin lookups running at the same time
- In-memory images: Number of images (flags, tracker icons) kept in memory. Set to 0 to disable in-memory image caching

Cached data:

For each cache, RT# displays its current size, and you can empty it with the "Clear" button:

- AS cache: Caches the autonomous system (ISP/network) information for IP addresses seen in the peers list
- Torrent file cache: Caches the list of files contained in each torrent to avoid re-fetching it from the daemon
- Torrent properties cache: Caches basic torrent properties such as whether a torrent contains multiple files
- Image cache: Caches the scaled favicons and other images fetched from remote sources

Clearing a cache is completely safe, the information will simply be fetched again the next time it is needed. This can be useful if a tracker has changed its icon or if a network has changed its owner.
