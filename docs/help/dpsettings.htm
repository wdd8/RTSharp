Each data provider has its own settings window that displays the settings of the torrent daemon itself, so you don't need to open the web interface of the daemon to change them. Select the data provider instance in the Plugins window and click on the settings button. When you have made your changes, click on "Save settings" to send them to the daemon.

1. rtorrent:

The settings of rtorrent are displayed as a list of settings with their value. Just click on a value to modify it.

2. qBittorrent:

The settings window looks like the options of qBittorrent and contains almost all of them: adding torrents, saving management, monitored folders, external program, listening port, connection limits, proxy server, IP filtering, rate limits, privacy, seeding limits, RSS, web user interface, and the advanced qBittorrent and libtorrent settings.

3. Transmission:

The settings window contains the default download folder on the server, the global bandwidth settings, the seeding limits and the network settings (peer exchange, DHT, local peer discovery, µTP).

Polling:

The qBittorrent and Transmission settings windows also have a "List update interval" setting, which is how often RT# asks the daemon for the changes of the torrent listing, in seconds.
