The Files tab displays the files of the selected torrent with their folders as a tree. For each file, RT# displays the following columns:

Name: Name of the file or of the folder, with an icon depending on the type of file
Size: Size of the file
Downloaded: Amount of data already downloaded
Done: Progress of the file
Priority: Download priority of the file
Download strategy: How the pieces of the file are downloaded

The files are refreshed automatically while the tab is visible, the refresh interval can be adjusted in the Behavior options. Since the list of files of a torrent never changes, RT# keeps it in a local cache so it does not need to be fetched again from the server (see the Caching options).

Select one or several files and right click on them to get the files menu:

- Mediainfo: Run mediainfo on the server for the selected files and display the result in a new window. This gives you all the details about a video or an audio file without downloading it
- Preview with mpv: Play the file with mpv directly from the server
- Priority: Set the priority of the selected files to "Don't download", "Normal" or "High"

Preview with mpv:

For direct file previews, RT# starts a small private web server on your computer that streams the file from RTSharp.Daemon, and mpv simply plays this local address. Moreover mpv can seek in the file, so you can jump anywhere in a video. mpv must be installed on your computer and available in the PATH, otherwise RT# will tell you that it has not been found. The preview stops as soon as you close mpv.
