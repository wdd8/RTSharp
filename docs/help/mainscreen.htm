The menu

The menu is located on top of the main window and gives you a quick access to all the windows of RT#. From left to right:

File: Add torrent..., About, About framework, Exit
View: Statistics
Tools: Torrent Creator, Options... and the tools added by the plugins
Plugins: Display the loaded plugins and manage their configuration
Servers: Add, edit or remove the servers running RTSharp.Daemon
Help: Contents (F1)

Some plugins can also add their own menu, for example the server script playground adds a "Server scripting" menu.

The tool bar

The tool bar just above the torrent listing gives you a quick access to the most important actions. From left to right:

Start: Start the selected torrents
Pause: Pause the selected torrents
Stop: Stop the selected torrents
Options: Open the options window

The torrent listing

It displays all the torrents of all your data providers in a single list, one line for each torrent. The background color of each line is the color of the data provider the torrent belongs to, if any. This is explained in detail in the "Torrent listing" chapter.

The details tabs

When you select one torrent in the listing, RT# displays its details in the four tabs below the listing: General, Files, Peers and Trackers. If you select several torrents, the General tab displays a summary of the selection. You can adjust the height of the listing and of the tabs with the splitter between them.

The data providers pane

The pane on the right side displays each data provider with its state, its latency to the server, the number of active torrents, the total download and upload speed and a speed chart.

The action queue and the log

Next to the torrent listing there are two more tabs: the action queue, which displays the progress of every action sent to the servers, and the log, which displays the messages of the application.

Arranging the windows

All the tabs and panes can be moved: just drag a tab by its title and drop it to another side of the window, or outside of the main window to make it a floating window. RT# memorizes the position and the size of the main window, the layout of the tabs, the columns of the listing and the height of the splitter, they will be restored the next time you start RT#.

While RT# is running, the title of the main window and the tooltip of the tray icon display the total upload and download speed of all your data providers. The tray icon menu has an "Exit" item to close the application.
