Each time you perform an action on some torrents (start, recheck, move, add...), RT# puts the action in the action queue in the background. The "Action queue" tab displays all these actions, grouped by server.

On top of each server, the queue displays the name of the server and the number of actions waiting in a blue bubble. For each action, the queue displays its name, its progress bar and a short text about what is being done. Some actions are made of several steps, for example adding a torrent that must be rechecked and started is made of an "Add" step, a "Recheck" step and a "Start torrents" step, each step starts only when the previous one has succeeded.

If some actions fail, a red bubble with an exclamation mark and the number of failed actions appears next to the name of the server. The detailed error is written in the log.

Right click on an action and select "Cancel" to stop it, this is only possible for the actions that can be cancelled.

Plugins can register their own queues and display them in a different way.
