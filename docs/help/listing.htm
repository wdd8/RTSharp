The columns

The listing displays one line for each torrent, with the following columns:

Connection: Name of the data provider instance the torrent belongs to
Hash: A small colored glyph computed from the info hash, the same torrent on two daemons has the same glyph
Name: Name of the torrent
State: Downloading, Seeding, Hashing, Paused, Stopped, Complete, Queued, Errored, Allocating...
Size: Total size of the torrent
Done: Progress bar of the download, the bar has a different color while the torrent is hashing
Downloaded / Completed / Uploaded / Remaining: Amount of data
DL Speed / Hashing Speed / DL + Hashing Speed / UP Speed: Current speeds
Peers / Seeders: Connected peers and seeders, with the total in brackets
Labels: Labels of the torrent
ETA: Estimated time left before the download is finished
Created On / Added On / Finished On: Dates of the torrent
Ratio: Share ratio
Tracker: Icon and name of the main tracker
Priority: Priority of the torrent

Right click on a column header and select "Columns" to show or hide any column. You can also resize the columns, and change their order by dragging the column header to its new position.

Sorting

Click on a column header to sort the listing on this column. Each click switches from ascending to descending, then back to the original order. You can sort on several columns at the same time, the listing will be sorted on the first column, then on the second one, and so on.

Filtering

Some column headers have a small funnel button, if you click on it you will get a filter for this column:

- Connection: Only display the torrents of the checked data providers
- Hash: Only display the torrent with this info hash (in hexadecimal)
- Name: Only display the torrents whose name contains the text
- State: Only display the torrents in one of the checked states
- Label: Only display the torrents with one of the checked labels
- Tracker: Only display the torrents of the checked trackers

Click on "Apply" to activate the filter or on "Clear" to remove it. The filters can be combined, for example you can display only the torrents of one tracker that are seeding on one data provider.

Search as you go

Just click in the listing and start typing the beginning of the name of a torrent, RT# will select the first torrent that matches and scroll to it. The search also looks at the labels and the tracker name, and it is not case dependent. The text that you have typed is displayed in the middle of the listing. Press Backspace to remove the last character or Escape to cancel the search. If you stop typing, the search is automatically cleared after a short delay that you can adjust in the Behavior options.

Selecting and copying

You can select several torrents with the Ctrl and Shift keys, or select all the torrents with Ctrl+A. Click on an empty area of the listing to clear the selection. Press Ctrl+C to copy the selected lines to the clipboard, the hash is copied in hexadecimal and the progress as a percentage, so you can paste them directly in a spreadsheet.

Colors

If a color has been set for a data provider, all its torrents are displayed with this background color, and the text is automatically displayed in black or white depending on the brightness of the color.

The columns, the sorting and the filters are saved when you exit RT# and they will be restored the next time.
