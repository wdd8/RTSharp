Let's start with a basic plugin. The easiest way is to derive from BasePlugin<TConfig>, where TConfig is the configuration class of the plugin. If the plugin has no settings, just use PluginConfigContainer<PluginInstanceConfig>:

public class Plugin : BasePlugin<PluginConfigContainer<PluginInstanceConfig>>
{
    public override string Name => "Hello";
    public override string Description => "Says hello";
    public override string Author => "Me";
    public override int CompatibleMajorVersion => 0;
    public override Guid GUID { get; } = new Guid("00000000-0000-0000-0000-000000000000"); // generate your own!
    public override PluginCapabilities Capabilities => new(HasSettingsWindow: false);

    IDisposable? MenuItem;

    public override Task<IPlugin> Init(IPluginHost<PluginConfigContainer<PluginInstanceConfig>> Host, Action<(string Status, float Percentage)> Progress)
    {
        Progress(("Initializing...", 0f));

        Dispatcher.UIThread.Invoke(() => {
            MenuItem = Host.RegisterToolsMenuItem(new MenuItem {
                Header = "Say hello",
                Command = new RelayCommand(() => Host.ShowTrayMessage("Hello", $"{Host.Torrents.Count} torrents"))
            });
        });

        Progress(("Done", 100f));
        return Task.FromResult((IPlugin)this);
    }

    public override Task Unload()
    {
        MenuItem?.Dispose();
        return Task.CompletedTask;
    }
}

Each Register and Hook function of the host returns an IDisposable, dispose it in Unload to remove what you have registered. Since menu items are Avalonia controls, create them on the UI thread.

What can a plugin do?

- RegisterRootMenuItem: Add a menu to the main menu bar
- RegisterToolsMenuItem: Add an item to the Tools menu
- RegisterTorrentContextMenuItem: Add an item to the torrent menu of the listing, the command receives the selected torrents
- HookTorrentListingEvLoadingRow / HookTorrentListingEvLoadingCell: Change the appearance of the lines or of the cells of one column of the listing (this is how the colored ratio plugin works)
- HookAddTorrentEvDragDrop: Modify the Add torrent window when a file is dropped
- RegisterActionQueue: Display your own action queue
- RegisterDataProvider: Register a torrent data provider, see the next chapter
- Torrents / GetDaemonServices: Access all the torrents and all the servers
- ShowPluginSettings: Display a settings window, set HasSettingsWindow to true in the capabilities
- CustomAccess: Exchange data with another plugin
- ConfigureServices: Register your own services in the dependency injection of RT#

Running code on the server:

IDaemonService gives access to everything the server offers: file system information, mediainfo, file transfers, and of course the scripts. A plugin can run a script with RunCustomScript, wait for its result with GetScriptProgress and exchange messages with it, or install it permanently with InstallScript. The format of the scripts is described in the "Server scripts" chapter. The auto integrify plugin is a good example, it runs a script on the server to search the files.

* The IPluginHost.MainWindow property can be used to make direct modifications to the main window, but this might break on any version update.
