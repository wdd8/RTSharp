Each data provider is a plugin. Plugins are enabled by their configuration files, so you can have multiple instances of the same data provider running for different torrent daemons.

Before you start, make sure that the torrent daemon is declared in the DataProviders section of the daemon configuration (see the "Data provider configuration" chapter) and that the server has been added in the Servers window.

Click on the "Plugins" menu, then click on "Manage...". The Manage Plugins window is divided in two parts: the available plugins on the left and the configured plugins on the right. Select the data provider corresponding to your torrent daemon in the available plugins, for example "RTSharp.DataProvider.Qbittorrent.Plugin", and click on the ">" button. You will then be asked to enter some information about this new instance:

- Instance name: Unique name for this data provider instance, as it will be displayed in the GUI (ie. in the Connection column)
- Server: One of the servers you have configured before
- Data provider name (on daemon): The name of the torrent daemon as specified in the daemon configuration, for example "my qbittorrent"
- Color: Optional color of the instance, the lines of its torrents will be displayed with this background color

Click on "Create" and the new instance will appear in the configured plugins. You can edit an instance by double clicking on it, and remove it by selecting it and clicking on the "<" button.

When you close the Manage Plugins window after a change, RT# tells you that the plugin configuration has changed. The changes are only applied after you restart the application. After the restart you should see the data provider in the data providers pane, and its torrents in the listing if there are any.

Congratulations, you have just configured your first data provider!

The other plugins (auto integrify, colored ratio...) are configured exactly the same way, except that they don't need a server or a data provider name.
