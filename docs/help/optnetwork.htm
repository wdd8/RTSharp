Proxy:

- Use proxy: Send all the connections of RT# through a proxy, including the connections to the servers
- Address: Address of the proxy, for example socks5://127.0.0.1:1080. The supported schemes are socks4, socks4a and socks5. If the address is not valid, RT# displays "Invalid proxy address"
- Username / Password: Credentials of the proxy, if required

* The proxy password is stored in plain text in the configuration file.
