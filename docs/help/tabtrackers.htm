The Trackers tab displays the trackers of the selected torrent, with the following columns:

Icon: Icon of the tracker
Tracker: Name of the tracker, move the mouse over it to see its full address
Status: Status of the tracker
Seeders / Peers / Downloaded: Statistics returned by the tracker
Last updated: Last time the tracker has been contacted
Interval: Time between two announces
Message: Last message returned by the tracker

Right click on a tracker to get the trackers menu:

- Add a new tracker...: Add another tracker to the torrent
- Enable / Disable: Enable or disable the tracker
- Remove: Remove the tracker from the torrent
- Replace: Replace the address of the tracker by a new one
- Reannounce: Announce to this tracker immediately
- Set name...: Give a friendly name to the tracker
- Set icon...: Select an image on your computer to use as icon
- Fetch icon: Download the icon (favicon) of the tracker web site again

Tracker names and icons:

The names and the icons of the trackers are saved in a local database and they are shared by all the torrents of the same tracker domain. They are also used in the Tracker column of the listing and in its filter, so it is a good habit to give a short name to each of your trackers. The icons are downloaded automatically from the tracker web site, you can choose to download them via the Google favicon API in the Behavior options.

* The menu items are only enabled when the torrent daemon supports them, see the "Torrent daemons" chapter.
