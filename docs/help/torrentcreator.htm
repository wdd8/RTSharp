The torrent creator creates .torrent files from the files of your computer. Select "Torrent Creator" in the Tools menu, here is how it works:

1. Select file/folder:

Drag and drop a file or a folder on the drag and drop area, or click on "Select file" or on "Select folder". You can also type the path directly.

2. Settings:

- Piece size: Size of the pieces, from 16 KiB to 32 MiB. "Auto" selects a size depending on the total size of the data. Click on "Calculate number of pieces" to know how many pieces the torrent will have
- Private torrent: The torrent won't be distributed on the DHT network, the peers will only come from the trackers
- Add entropy: Add some random data to the torrent so it is unique, even if somebody else creates a torrent from the same files
- Emit creation date: Save the creation date in the torrent
- Version: V1, V2 or Hybrid. Hybrid torrents work with both V1 and V2 clients
- Optimise alignment: Align the files larger than the given size to the piece boundaries, this way each of these files starts with a new piece.

3. Fields:

- Tracker URLs: The addresses of the trackers, one per line
- Web seed URLs: The addresses of web servers hosting the same files, one per line
- Comments: A comment displayed by the torrent clients
- Source: A source tag, optional

4. Create:

Click on "Create Torrent" and select where the .torrent file must be saved. RT# then reads and hashes all the files, the progress window displays the progress of the current file, of the read buffer and of the hashing. You can click on "Cancel" at any time.

* Remember that V2-only torrents are only accepted by qBittorrent, if you want to add the torrent to rtorrent or Transmission, create a V1 or a hybrid torrent.
