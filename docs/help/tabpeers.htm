The Peers tab displays the peers connected to the selected torrent, with the following columns:

Icon: Flag of the country of the peer
Origin: Name of the company that owns the network of the peer, followed by its domain in brackets
IP:Port: Address of the peer
Client: Torrent client of the peer
Flags: Connection flags reported by the torrent daemon
Done: How much of the torrent the peer has
DL Speed / UP Speed: Current speeds between you and the peer
Downloaded / Uploaded: Amount of data transferred with this peer
Peer DL Speed: Estimated download speed of the peer

Peer origin:

Each time a new peer appears, RT# looks up the owner of its IP address. While the lookup is in progress or is not needed, the origin is displayed as "Loading...", and if nothing can be found it is displayed as "Unknown". There are two lookup methods that you can select in the Behavior options:

- RDAP (via ARIN): A direct query that returns whois data. The name is then resolved from the whois data, which can lead to some inaccuracies
- CAIDA + Team Cymru: Maps the IP to its network (ASN) via whois.cymru.com, then resolves the network to a company name using the CAIDA dataset. This produces more accurate company names but requires a dataset download and queries an API for every lookup

The results are saved in the AS cache, so a network is only looked up once. Some domains are not very meaningful, you can replace them with your own text with the peer origin replacements of the Behavior options.

Peers menu:

- Add peer...: Enter the address of a peer as IP:Port and press Enter, the torrent daemon will try to connect to it
- Ban peer: Ban the selected peer

* Transmission does not support adding or banning peers.
