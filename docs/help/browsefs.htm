RT# can browse the files and folders of a server, and tell you which torrents each of them belongs to. Open the Servers window, select a server and click on "Browse file system".

The window opens on the root of the server. Double click on a folder to open it, or on ".." to go to the parent folder. You can also type a path in the box at the top and press Enter, and F5 refreshes the current folder. For each file or folder, RT# displays the following columns:

Name: Name of the file or of the folder, followed by the target of the symbolic links
Permissions: Type and permissions of the file, hover them to see the owner and the group
Size: Size of the file
Last modified: Date of the last modification
Torrents: The torrents whose data is this file or folder, or contains it, with the data provider they belong to. Hover a torrent to see its info hash

The Torrents column covers all the data providers attached to the server, so several torrents are listed when a folder is shared between them, for example by cross-seeded torrents. The folders inside the data of a torrent show that torrent as well, so you can tell where any file comes from. The torrents are those known to RT# when the folder was opened, press F5 to refresh them.

Select one or several files and right click on them to get the files menu:

- Mediainfo: Run mediainfo on the server for the selected files and display the result in a new window
- Preview with mpv: Play the file with mpv directly from the server, as in the Files tab
- Remove directory: Remove the selected empty directory

The "Create directory" button creates a new folder in the current folder.
