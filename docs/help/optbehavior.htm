Select "Options..." in the Tools menu (or click on the gear button of the tool bar) to open the options window. The options are organized in four pages: Behavior, Caching, Look and Network. Click on "Apply" to save your changes, on "OK" to save them and close the window, or on "Cancel" to close the window without saving.

Polling intervals:

- Files polling interval: How often the Files tab is refreshed, in seconds
- Peers polling interval: How often the Peers tab is refreshed, in seconds
- Trackers polling interval: How often the Trackers tab is refreshed, in seconds
- Search-as-you-go delay: How long the search text of the listing is kept after you stop typing, in seconds
- Poll selected torrent's active detail tab only: When this option is checked, only the details tab currently in view (Files, Peers or Trackers) is refreshed, instead of all of them at once. This reduces the load on the servers

Torrents:

- Automatically start torrents after a recheck: When this option is checked, a torrent that finishes rechecking and is fully complete will be started automatically

Favicons:

- Use Google favicon API: Fetching the tracker icons via Google is more stable, but it sends the domain you're looking up to Google

Peer origin lookup:

Select the method used to find the origin of the peers, "RDAP (via ARIN)" or "CAIDA + Team Cymru". Move the mouse over the list to get a description of each method, they are also described in the "Peers tab" chapter.

Peer origin replacements:

This list allows you to replace the domain displayed in brackets in the Origin column by your own text. Click on "Add", enter the exact domain as the pattern and the text to display as the replacement, then press Enter. To remove a replacement, select it and click on "Remove".
